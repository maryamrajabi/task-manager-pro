# Task Manager Pro

Task Manager Pro is a project-based full-stack application built with Angular and Spring Boot.

## Product Goal

Help users create, organize, prioritize, and track their tasks through a clean and secure experience.

## Workspace

- `frontend/` — Angular application
- `backend/` — Spring Boot API
- `docs/` — Product, API, and architecture documentation
