# Product Brief

## Product

Task Manager Pro

## Problem

Many learners understand isolated programming concepts but struggle to build and deliver a complete product.

## Goal

Build a task management product that demonstrates a real Angular and Spring Boot workflow.

## MVP

* Register and login
* Create, view, edit, and delete tasks
* Task status and priority
* Search, filter, and sort
* Loading, empty, and error states
* Responsive user interface
* Build and deployment

## Out of Scope

* Chat
* Real-time collaboration
* File upload
* Complex team permissions
* Microservices
